# 02 · 中断与预估操作手册

> 两件事：**打断来了怎么办**（第 4 章）、**怎么估得越来越准**（第 5 章）。
> 这两块是全书可执行度最高的部分，也是用得最烂的部分——多数人只记住「25 分钟」，把这两块丢了。

---

# 第一部分：中断

## 一、先分清类型，再谈策略

| | 内部中断 | 外部中断 |
|---|---|---|
| 来源 | 自己冒出来的念头 | 别人找上来 |
| 符号 | `'` 撇号 | `-` 减号 |
| 特征 | 无人在等你 | 有人正在等你答复 |
| 策略 | 接受 → 记录 → 继续 | 告知 → 协商 → 计划 → 答复 |
| 失败模式 | 记了但没做，晚上发现一堆 U | 协商了但没答复，下次没人信 |

**为什么必须分开记**：两类中断的成因和解法完全不同。撇号多说明任务本身有问题（太模糊、太难、你在逃）；减号多说明环境有问题（座位、时段、岗位性质）。混在一起记，你只会得到一个「今天被打断 12 次」的无用数字。

书里 79 节给了一个完整例子，值得照着做一遍：

> 早晨选了「准备发票」「领达尔文奖」「填纳税表」。先做纳税表。
> ① 准备发票时想起要给埃达打电话 → 记活动清单 → 在「准备发票」右边标撇号
> ② 填纳税表时比娜来电 → 告诉她正忙、稍后回 → 在「填纳税表」右边画减号
> ③ 同时在「计划外紧急」区写「电话比娜」

三个动作，三处记录，缺一不可。

## 二、内部中断：完整分支

### 流程

```
念头冒出来
  │
  ├─ 是生理需求（上厕所、必须吃药）？
  │     └─ 是 → 按规则 4 作废当前番茄钟，回来重开
  │
  └─ 不是
        │
        ├─ 今天是必须做的？
        │     └─ 是 → 写进「今日待办」下方「计划外紧急」区
        │
        ├─ 今天不做，但有截止时间？
        │     └─ 是 → 写进「活动清单」，条目前加 U，标截止时间
        │
        ├─ 纯杂念（想刷网站、想看看新闻）？
        │     └─ 是 → 什么也不写，就记一个撇号，继续
        │
        └─ 然后在当前活动右边画 ' → 继续当前番茄钟
```

### 三个关键判断

**判断 1：这事真的急吗？**

书里 70 节的观察很准：「**在此时此刻看似刻不容缓的事情，当真的罗列出所有任务、纵览全局时，它往往又不那么显眼了。**」

实操版：问自己一句「这件事如果 25 分钟后做，会有什么后果？」——90% 的答案是「没有后果」。

**判断 2：写下来之后，念头会不会消失？**

如果写完还在想，说明你写得太简略了。书里强调要「不让它占我的脑子」——写下来的目的不是备忘，是**卸载工作记忆**。写清楚到「明天早上看到就知道要做什么」的程度，念头才会真的退场。

**判断 3：撇号密集出现说明什么？**

书里 73 节的处理方式很有意思：

> 「要解决问题，首先缩小番茄钟，尝试改为 15、10 甚至 5 分钟。等到发现自己每天都能画下不少的 X 的时候，你就可以延长番茄钟到 20 分钟，最后到 25 分钟。」

注意这个逻辑：**它不要求你「意志力更强」，而是降低门槛让成功变得可能。** 5 分钟里能专注，就先拿 5 分钟的 X；能稳定拿到 X 了，再往上加。

这条对拖延者特别有效——拖延的核心不是懒，是启动成本太高。5 分钟的门槛低到无法拒绝，而一旦开始，多数人会自然做下去。

**代价**：5 分钟的 X 和 25 分钟的 X 不可比。书里明说「你应当保持较短的番茄钟至少两个星期」，就是让这段数据自成一段基线。

### 内部中断的根因：三种

书里 69 节列了三种，值得对照自查：

| 根因 | 表现 | 对策 |
|---|---|---|
| **任务太复杂** | 想到就烦，于是去干别的 | 拆小，拆到「这一步我知道怎么做」为止 |
| **担心质量/被批评** | 迟迟不肯开始，因为怕做不好 | 先做一版丑的；书里 9 节：「别考虑任务有多复杂，重要的是开始、再开始」 |
| **没弄清怎么开始** | 卡在第一步 | 花一个番茄钟只做「搞清楚怎么做」这件事，允许它没有产出 |

第三种最隐蔽：你以为自己在专注，其实在反复读同一段材料。**识别方法**：一个番茄钟结束，你能不能用一句话说出「下一步做什么」？不能，就是卡在这里。

## 三、外部中断：完整分支

### 四步策略

| 步 | 话术 | 常见错误 |
|---|---|---|
| **告知** | 「我手头有事，正忙。」 | 解释太多，反而给了对方继续的理由 |
| **协商** | 「X 点之后帮你，行吗？」 | 说「稍后」而不给时间点 → 对方会再来 |
| **计划** | 写下活动名，为它排一个未来的番茄钟 | 只口头答应，不落纸 → 一定忘 |
| **答复** | 到点主动回复 | 忘了第 4 步 → 前 3 步白做，且信用破产 |

书里 76 节强调「可视化然后强化」：**每遇到一次外部中断，就在今日待办写上中断所要求活动的标题，然后画减号，然后增强决心完成当前番茄钟。**

三步的顺序不能乱：先写（卸载），再记（留痕），再回神。如果先回神再写，写的时候已经忘了。

### 五种典型的「不该拒绝」

书里 75、77、113 节给了明确边界，这几条比策略本身更重要——**用错这套方法的人，多半是在这里出问题**：

| 情形 | 处理 | 依据 |
|---|---|---|
| **团队内请教工作问题** | 可以不计入外部中断（团队约定） | 113 节 |
| **你造成的故障，别人卡住了** | 立即作废番茄钟去处理 | 77 节（代码编译不过的例子） |
| **上级的紧急指令** | 作废，处理完休息后再开新番茄钟 | 同上逻辑 |
| **对方不接受延迟** | 作废，别硬撑 | 75 节「在对方接受的范围内」 |
| **同事只是想聊两句** | 可以延迟，而且应该延迟 | 75 节 |

书里 75 节原话：「别把番茄工作法当成拒绝帮助同事的理由，它可不是专门给古墓派闭关修炼用的。」

### 邮件和电话：最容易的一类

- **处理方式**：关掉。发邮件的人不期待 25 分钟内收到回复。
- **查看时机**：每半小时，在换「战略帽」、排序优先级之前，扫一眼**标题**。
- **禁止**：在番茄钟内读全文，更不要回复。
- **回复本身要占番茄钟**：书里 96 节作者的做法是「每天分配两个番茄钟来写回信」。回复不是休息，是工作。

### 中断频率的诊断价值

这是全 skill 最有用的一张表（书里没给，是我加的判据）：

| 观察 | 含义 | 动作 |
|---|---|---|
| 减号 > 1.5 次/番茄钟 | 环境不允许 25 分钟连续 | 缩短番茄钟到平均间隔以下，或换时段 |
| 撇号 > 2 次/番茄钟，且集中在某几件事 | 这几件事本身有问题 | 拆开，或先花一个番茄钟搞清怎么做 |
| 撇号和减号都很少，但 X 也不多 | 不是中断问题，是**任务太模糊** | 回到预估环节，重新拆 |
| 作废次数持续 > 完成次数 | 参数设置错了，不是意志力问题 | 立刻缩到 15 分钟试两周 |

## 四、作废：什么时候必须认

书里 72 节的规则很硬：「如果任务被放下了，无论是暂时的还是长期的，当前番茄钟都必须作废。」

**必须作废的情形**：

- 去洗手间、接必须接的电话、处理自己造成的故障
- 被拉去开一个无法拒绝的会
- 当前任务做完了但还剩很多时间 —— **这条例外，用过度学习填满，不作废**

**不许「补时」的情形**：

- 剩 10 分钟，回来接着做 → 不行，重开
- 剩 2 分钟，硬撑完 → 可以，但不许算作一个完整番茄钟的数据

**作废之后**：先休息一下，再扭新表。不要因为「刚才浪费了 15 分钟」就跳过休息赶进度——那会让下一个番茄钟质量更差。

> **心理层面最重要的一句**（72 节）：「『完成的番茄钟数』不是拿来衡量工作能力的，没有这个标准。它只是记录你所付出的 25 分钟连续的努力。」

如果作废让你产生「今天废了」的感觉，说明你把番茄数当成了成绩单，而这正是第 9 条守则要禁止的。

# 第二部分：预估

## 五、为什么预估是这套方法的另一半

书里 85 节：「如果事前预估与实际所花工夫之间经常不一致，有以下两种可能的原因：① 做预估的方法或能力有待改进；② 工作开始后，又出现新情况、新问题。」

第二种你控制不了。第一种可以练，而练习的唯一途径就是**记录误差并回看**。

> 没有预估的番茄工作法，只是一个「25 分钟计时器 + 打断计数」。加上预估，它才变成一套**校准系统**——你会逐渐知道自己估事的能力偏差多少，然后开始修正。

---

## 六、三级预估的完整算法

### 一次预估（计划阶段）

1. 从活动清单挑出今天要做的几项，抄进今日待办
2. 给每项写一个整数番茄数
3. 在活动名右边画对应个数的小方格 `□ □ □`

**规则**：
- 不能写小数（1/2、2.2 都不行）
- 预估 > 7 → 拆开，每块单独一行、单独预估
- 预估 < 1 → 标 `0`，仍占一行；计划时可以把几个 0 合并成一行

**例**：

```
今日待办  10月17日  张三
─────────────────────────
填纳税表            □ □
准备发票            □ □ □
给埃达打电话         □
回复昨日邮件 0+0+0   □
```

### 二次预估（方格用完，事没完）

在方格右边按新估值画**圆圈** `○ ○`。

```
填纳税表  □ □ ○ ○        ← 原本估 2，实际要 4
```

**这一步的意义**：它把「我低估了」这件事**当场可见**，而不是等到晚上才发现。可见之后，你有机会立刻调整当天剩下的计划（少排一件），而不是硬塞。

### 三次预估（圆圈也光了）

用**三角形** `△`，这是最终预估。

```
填纳税表  □ □ ○ ○ △ △ △
```

**三次还不够怎么办**（89 节）：「那真是有点失败了。你得分析一下，为什么一次又一次反复地低估这件事？**也许应当将活动拆开，降低复杂度。**」

**这是全方法的报警灯**：连续三次低估同一件事，说明你对它的结构理解是错的，不是「估少了」这么简单。这时候该做的是拆解，不是继续加三角。

## 七、记录表怎么算

### 两列新指标

| 列 | 算法 | 目标 |
|---|---|---|
| **总体预估误差** | Σ(每项的高估量) − Σ(每项的低估量) | 趋近 0 |
| **重新预估次数** | 画了圆或三角的行数 | 趋近 0 |

### 算例（书里 91 节的例子，展开）

今天完成 4 项：

| 活动 | 预估 | 实际 | 差 |
|---|---|---|---|
| A | 5 | 2 | +3（高估 3） |
| B | 3 | 1 | +2（高估 2） |
| C | 2 | 0 | +2（高估 2） |
| D | 4 | 6 | −2（低估 2） |

```
总体预估误差 = (+3) + (+2) + (+2) + (−2) = +5
```

**读法**：今天预留的方格比实际用量多了 5 个 → **你整体高估了自己的速度**。明天同样大小的承诺，砍掉 5 个番茄钟的量。

### 为什么要「正负抵消」

书里 91 节：「新问题和新情况既可能降低、也可能增加活动的难度，以长期的眼光来看，这些误差应该能相互抵消。」

这句话的意思是：**单日的正负没有意义，趋势才有意义。**

- 连续一周都是 +8、+6、+10 → 你系统性高估，明天少排
- 连续一周都是 −5、−3、−7 → 你系统性低估，该拆活动了
- 正负交替、绝对值小 → 你估得准，可以不动

**单日看得失，周看趋势。** 这是一条很容易违反的纪律——人天生会盯着今天的 +5 懊恼，而不会去看七天的均值。

## 八、预估的三个常见错误

### 错误 1：把预估值当承诺

书里 56 节：「预测一件事要花多久，然后发现你的猜测被当成了承诺，这真让人郁闷。」

番茄工作法的预估值**只对你自己有意义**，它的用途是「决定今天排多少事」，不是「答应别人什么时候交付」。

如果你需要对外承诺，用**区间**加**进度沟通**，不要用番茄数换算成小时去承诺——25 分钟是「尽力工作的时间」，不是「产出时间」。

### 错误 2：按「理想状态」估

新手普遍按「没人打扰、状态好、一次做对」来估。三个假设都不成立。

**修正法**：第一次估完之后，乘以你记录表里的历史偏差系数。如果连续四周你的总体误差都是 +40% 左右，那就在每次估完之后**自动加四成**，不要靠「这次我会估准」的意志力。

### 错误 3：拆得不够细

书里 87 节给的阈值是 7，Cirillo 原版是 5–7。但真正的判据不是数字，是**你能不能在脑子里过一遍这件事的步骤**。

> 如果你说不出「第一步做什么、第二步做什么」，那这个活动的预估必然是猜的。**先花一个番茄钟把它拆开，这一步本身值得一个 X。**

## 九、缓冲区：活动清单该多长

书里 92 节引入了约束理论的「鼓-缓冲区-绳子」：

| 概念 | 对应 |
|---|---|
| **鼓** | 你每天完成的番茄数（节奏） |
| **缓冲区** | 活动清单里所有活动的预估番茄总数 |
| **绳子** | 约束信号，控制要不要往清单里加新活动 |

**算法**：`缓冲区目标 = 日流量 × 缓冲天数`

书里的例子：每天 9 个番茄钟，想要 10 天缓冲 → 活动清单的预估总数应在 **90 左右**。

- **远超 90** → 过剩。陈年旧账会「扰乱军心，甚至引你误入歧途」（92 节）。清理，删掉已经不重要的。
- **远低于 90** → 萧条。清单空了，需要主动找活，或请上级/客户补充。

> 这一条对自由职业者和独立研究者特别有用——他们的典型问题不是活太多，而是**清单里全是做不完的大项目，导致永远没有「完成」的反馈**。

## 十、一个完整的日循环示例

```
08:50  计划（3 分钟）
       活动清单 → 挑 5 项 → 今日待办
       预估：A□ □ □  B□ □  C□  D□ □ □ □  E□
       合计 11 个，日流量 8 → 太多了，去掉 E，D 拆成两半
       → A□ □ □  B□ □  C□  D1□ □  D2□ □   合计 9

09:00  A 第 1 个番茄钟
       09:12 想起要订票 → 写「计划外紧急」→ 画 ' → 继续
       09:25 响 → 画 X → 起身倒水 3 分钟

09:28  A 第 2 个番茄钟
       09:35 同事来问 → 告知/协商「11 点后」→ 画 - → 继续
       09:50 A 提前做完 → 用剩余 3 分钟检查错漏（过度学习）
       09:53 响 → 画 X → 划掉 A

...

17:50  记录（3 分钟）
       X 总数 7（目标 8，差 1）
       撇号 5  减号 3
       预估误差：A +0  B +1  C +0  D1 −2  D2 未完成
       → 总体 +1−2 = −1，基本准
       → 但 D1 低估 2，说明这类任务我总估少
17:55  可视化
       明天的改动：D 类任务预估自动 +2
```

**这个例子里最有价值的三行是末尾**：不是「今天完成 7 个」，而是「D 类任务我总估少」「撇号 5 次偏多」「减号 3 次可接受」。**只有这三行能改变明天的行为。**
