# 三张表模板

> 照抄下面三个框，用手写也行，用表格软件也行。**建议第一周用纸**——纸的边界感比软件强，而且不会顺手切走。
>
> 只需要：一支笔 + 一个计时器（厨房定时器最好，因为它有「扭」的动作）+ 三张纸。

---

## 表一 · 活动清单

**生命周期**：多天复用。**容量**：25–30 项。**满了怎么办**：把未完成的誊到新表，旧的扔掉。

```
┌──────────────────────────────────────────────────────────┐
│ 活动清单                                    姓名：______ │
├────┬────────────────────────────────┬────────┬─────────┤
│ U  │ 活动（写「完成后的状态」，不写做法）  │ 预估番茄 │ 截止   │
├────┼────────────────────────────────┼────────┼─────────┤
│    │                                │        │         │
│    │                                │        │         │
│    │                                │        │         │
│    │                                │        │         │
│    │                                │        │         │
│    │                                │        │         │
└────┴────────────────────────────────┴────────┴─────────┘
```

**填写规则**

| 项 | 规则 |
|---|---|
| **活动名** | 写完成后的状态，不写过程。「客厅整洁」✓ 「收拾客厅」✗ |
| | 第一个词是主题类型，第二个词说清要实现什么（书里 43 节的做法） |
| | 一个月后自己还看得懂——这是唯一的验收标准 |
| **U** | 计划外进来的（unplanned）在这里标 U，并写截止时间 |
| **预估番茄** | 整数。这是「要做几个 25 分钟」，不是「要几小时」 |
| **截止** | 有明确时点的才写，如「客厅整洁 7:00pm 请客」 |

## 表二 · 今日待办

**生命周期**：每天一张，隔天作废。**这是承诺，不是清单。**

```
┌──────────────────────────────────────────────────────────┐
│ 今日待办            日期：____年__月__日   姓名：______   │
├──────────────┬───────────────────────────┬──────────────┤
│ 活动          │ 番茄方格                  │ 中断标记      │
├──────────────┼───────────────────────────┼──────────────┤
│              │ □ □ □                     │ '  -         │
│              │                           │              │
├──────────────┼───────────────────────────┼──────────────┤
│              │ □ □                       │              │
│              │                           │              │
├──────────────┼───────────────────────────┼──────────────┤
│              │ □                         │              │
│              │                           │              │
├──────────────┴───────────────────────────┴──────────────┤
│ 计划外紧急                                                │
│  ·                                                        │
│  ·                                                        │
└──────────────────────────────────────────────────────────┘
```

**填写规则**

1. **只写今天真能做完的。** 写进去 = 拒绝了其他所有事。今天不打算做的，一个字都别写。
2. **每项画对应个数的小方格。** 一个方格 = 一个 25 分钟。
3. **预估总数不要超过你的「日流量」**（近一周每天 X 数的中位数）。
4. **计划外紧急区**只放两类：今天必须做的外部请求、突然想起的今日待办。

### 方格怎么演进

```
预估 2 个，实际 4 个：

  填纳税表   □ □ ○ ○           ← 方格用完 → 二次预估画圆圈

圆圈也光了，还需要 3 个：

  填纳税表   □ □ ○ ○ △ △ △    ← 三次预估画三角（最终）

三次还不够 → 停下来，拆开这件事，不要再加三角
```

## 表三 · 记录

**生命周期**：多天复用，一行一天。**这是唯一能让你变准的表。**

```
┌──────────────────────────────────────────────────────────────┐
│ 记录                                         姓名：______    │
├────────┬────────┬────────┬────────┬──────────┬─────────────┤
│ 日期    │ 完成 X │ 内部中断│ 外部中断│ 预估误差  │ 重新预估次数 │
│        │        │  （'）  │  （-）  │ （+/−）   │  (○+△ 行数)  │
├────────┼────────┼────────┼────────┼──────────┼─────────────┤
│        │        │        │        │          │             │
│        │        │        │        │          │             │
│        │        │        │        │          │             │
│        │        │        │        │          │             │
│        │        │        │        │          │             │
│        │        │        │        │          │             │
│        │        │        │        │          │             │
├────────┴────────┴────────┴────────┴──────────┴─────────────┤
│ 本周中位数 X：____   平均撇号：____   平均减号：____          │
│ 预估误差趋势：偏正 / 偏负 / 抵消    判断：____________        │
└──────────────────────────────────────────────────────────────┘
```

### 预估误差怎么算

```
总体预估误差 = Σ(高估的量) − Σ(低估的量)
```

**算例**（一天 4 项）：

| 活动 | 预估 | 实际 | 差 |
|---|---|---|---|
| A | 5 | 2 | +3 |
| B | 3 | 1 | +2 |
| C | 2 | 0 | +2 |
| D | 4 | 6 | −2 |

```
(+3) + (+2) + (+2) + (−2) = +5
```

**+5 的意思是**：今天预留的方格比实际用量多 5 个 → 你整体高估了 → 明天同样大小的承诺砍掉 5 个番茄钟的量。

### 三个数字分别看什么

| 数字 | 看什么 | 怎么用 |
|---|---|---|
| **X 数** | 近一周中位数 | 明天的计划量就按这个排，不按最好那天 |
| **撇号（内部中断）** | 是否集中在某几件事 | 集中 → 那几件事要拆；散在全部 → 缩短番茄钟 |
| **减号（外部中断）** | 是否 > 1.5 次/番茄钟 | 超过 → 环境不允许 25 分钟连续，缩短番茄钟或换时段 |

> ⚠️ **单日不看趋势，周看趋势。** 人天生盯着今天的 +5 懊恼，而改进行为靠的是七天的均值。
> ⚠️ **至少四周**再下结论。书里 120 节：「你需要采集大量的样本，才能作出结论。」

## 符号速查

| 符号 | 含义 | 画在哪 | 什么时候画 |
|---|---|---|---|
| `□` | 一个番茄钟的额度 | 活动右侧 | 计划阶段 |
| `X` | 完成了 | 小方格里 | 响铃之后，休息之前 |
| `○` | 二次预估 | 方格之后 | 方格用完、事还没完 |
| `△` | 三次预估（最终） | 圆圈之后 | 圆圈也用完 |
| `'` | 内部中断 | 活动右边 | 自己冒出一个念头 |
| `-` | 外部中断 | 活动右边 | 别人来找 |
| `U` | 计划外 | 活动清单条目前 | 不在原计划里的事 |
| `Y` | 会议番茄（可选） | 与 X 同位置 | 想把会议和独处工作分开统计时 |

## 每日三次动作（含具体分钟数）

```
【早晨 · 3 分钟】
  □ 翻活动清单，挑 3–6 项
  □ 抄进今日待办
  □ 每项写预估番茄数
  □ 画对应个数的小方格
  □ 合计 ≤ 昨日 X 数（或近一周中位数）

【每个番茄钟 · 25 + 3】
  □ 扭表
  □ 只做这一件
  □ 走神 → 记 ' → 继续
  □ 被打断 → 记 - → 协商 → 继续（或作废）
  □ 响了 → 画 X
  □ 起身离开桌子至少两步，3 分钟
  □ 每 4 个 → 长休 15–30 分钟

【傍晚 · 3 分钟】
  □ X 数写进记录
  □ 撇号数、减号数写进记录
  □ 算总体预估误差（正负抵消）
  □ 数有几行画了圆或三角
  □ 写一句：明天要改的一件事
```

## 卡片版（索引卡片替代方案）

如果嫌三张纸麻烦，书里给了卡片法（98 节）：**一件事一张卡**。

```
┌─────────────────────────────┐
│ 填纳税表            □ □     │   ← 黑色毡尖笔写标题
│                             │
│ 登录口令：...               │   ← 铅笔写补充信息
│ 参考：去年那张表            │
│                             │
│ 备注：                     │
└─────────────────────────────┘
```

**好处**：可以直接物理排序，每天只带今天那几张，翻牌就是换任务。
**代价**：卡片会越积越多，需要定期淘汰。

## 一页自检（打印出来贴桌上）

```
今天我只做一件事吗？           □ 是  □ 否
响了我就停了吗？               □ 是  □ 否
中断我记下来了吗？             □ 是  □ 否
今天填进待办的，是我真能做完的吗？ □ 是  □ 否
晚上我算过预估误差吗？          □ 是  □ 否
我把番茄数给谁看了吗？          □ 没有（正确）  □ 给了（停下来）

第 6 条答「给了」→ 重读守则第 9 条。
```
