# 番茄工作法 Skill

用 25 分钟原子时间盒 + 每日 PDCA，把「注意力」变成可计数的单位。

## 这是什么

一套五阶段的日循环，从《番茄工作法图解：简单易行的时间管理方法》（史蒂夫·诺特伯格著，原书 *Pomodoro Technique Illustrated*，2009）重排而来。

**紧凑版，有意为之。** 原书 39,110 中文字、7 章 130 个片段，但其中 20 节是装饰性的脑科学，真正可执行的内核不到三分之一。这本书自己主张「工具要简单」，那么解释它的东西也不该比它复杂。所以本 skill 只保留内核，并把省下的篇幅用在原书缺的两处：**番茄钟长度的选择判据** 和 **中断强度的分档处理**。

## 核心内容

### 五阶段（= PDCA）

```
早晨 → 计划 Plan → 跟踪 Track（每 25 分钟）→ 记录 Record → 处理 Process → 可视化 Visualize → 次日
```

**记录→处理→可视化这三步是分水岭。** 不做这三步，剩下只是一个手机倒计时。

### 三张表

| 表 | 生命周期 | 关键约束 |
|---|---|---|
| 活动清单 | 多天，25–30 项 | 不排序，随想随填 |
| 今日待办 | 每天一张 | **今天不打算做的不许写** |
| 记录 | 多天，一行一天 | 必须算预估误差，不只数 X |

### 六条硬规则

25 分钟硬停 / 不可分割 / 一旦开始必须走到响铃 / 中断即作废 / 响了先画 X 再休息 / 钟内只做一件事。

其中**只有「原子性」是结构性设计**，其余五条是可调约定。这个区分决定了你什么时候能改、什么时候不能改。

### 两套中断策略

- **内部**（`'`）：接受 → 记录 → 继续。把念头从脑子挪到日程表。
- **外部**（`-`）：告知 → 协商 → 计划 → 答复。四步缺一不可，缺第 4 步会让前 3 步失效。

### 三级预估

方格 `□` → 圆圈 `○`（二次）→ 三角 `△`（三次）。三次还不够，说明该拆活动，不是该继续加符号。

## 三个最有用的判据（书里没有的）

**1. 番茄钟该多长**

```
T = min( 注意力上限 , 平均无中断间隔 ) × 0.8
```

书里 73 节说「中断多就缩短」、101 节说「你自己定」、95 节说「两周别改」，三处散落没连起来。连起来就是这个公式。关键约束不是选多少，是**选定后至少两周不动**——不同长度的 X 数据不可比。

**2. 中断频率的诊断表**

| 观察 | 含义 | 动作 |
|---|---|---|
| 减号 > 1.5 次/番茄钟 | 环境不允许连续 | 缩短钟长或换时段 |
| 撇号 > 2 次且集中在某几件事 | 那几件事本身有问题 | 拆开 |
| 中断少但 X 也少 | 任务太模糊，不是中断问题 | 重新拆 |

**3. 什么时候该放弃这套方法**

一个番茄钟内能不能稳定产出 X？能，钟长合适；不能，不是意志力问题，是块太短或任务太糊。

## 一条必须说清的分歧

书里说「员工每 3 分钟被打断一次」，但**没给出处**，也**漏掉了同一研究的另一半**：被打断后恢复到原有深度平均要 **23 分 15 秒**（Mark, Gudith & Klocke, 2008）。

25 分钟减去 23 分钟，只剩 2 分钟。**这意味着一次真实的中断足以吃掉整个番茄钟**——而不是书里说的「记一笔继续」。

所以本 skill 把「按中断强度分档」提到主文件，作为选钟长的依据；书里把「作废」放在角落当例外。

## 三条最容易踩的坑

1. **把番茄数当 KPI。** 一旦开始对外汇报或自己定「每天必须 12 个」，作废机制立刻从「保护专注」变成「制造焦虑」，人会偷偷累加残段，方法当场失效。书里原话：「番茄数绝不是让老板给你打分用的。」
2. **只做前两步。** 早晨计划 + 白天扭表，晚上不记录。这样用一个月，你只会得到一个「我很忙」的感觉，不会得到任何可改的数字。
3. **两周内改参数。** 前两周你在学怎么执行，不是在这套方法适不适合你。此时改参数，等于在测自己的学习曲线。

## 与 Cirillo 原版的差异

本书是可靠的二手演绎，规则几乎一致，只有两处微差：拆分阈值（本书 7 个，原版 5–7 个）、短休长度（本书 3–5 分钟，原版 5 分钟）。
